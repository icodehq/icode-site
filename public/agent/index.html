Context that lasts

Running a long task is where coding agents fall apart: the window fills with old file reads and command output, the agent starts forgetting what it did, and every request costs more. iCode Agent treats context as a budget to defend, not a bucket to fill.

  • Cap at the source — oversized output is capped as it is produced and spilled to a file with a short preview.
  • Reduce at request time — older results become compact markers only when a request would exceed its budget, oldest first.
  • Summarize durably — when history truly overflows, older turns are summarized with a recent tail preserved.

A withheld result keeps a route back to the full output, failure evidence is never hidden, and reduction never rewrites your saved session.

Bring your own model

iCode Agent speaks the openai and anthropic protocols, so it works with the official APIs and any compatible endpoint. The agent runs locally; your code goes only to the model endpoint you configure.

Free and open source (Apache-2.0). You pay only your model provider.

How it fits with iCode Workbench.

Workbench (in early access) is the desktop environment for a team of agents — Claude Code, Codex, and OpenCode in isolated worktrees, with tasks, review, and Mira. Agent is the focused terminal surface: one repository, one session, no window. They are separate products with the same discipline, and either one can be used on its own.
